Resources & Acknowledgments

Project Concept

Idea: A dynamic and interactive "Digital Herbarium" focused on plants, inspired by a Pokédex from the Pokémon franchise.

Description: The website functions as a personal, searchable encyclopedia for a user's indoor plant collection. A user can search for a plant by its common name, which then triggers a backend process. The site fetches detailed botanical data from the Trefle.io API and displays it in a beautiful, informative "Plant Pokédex" card on the screen, complete with scientific name, family, and taxonomic information.

Reason for This Subject: I chose this subject because of my personal passion for plants and my own large collection at home. It merges a genuine interest with the project's technical requirements, allowing me to build something both useful and enjoyable. This idea provides an exciting opportunity to demonstrate mastery of modern web development skills, specifically the challenge of coordinating API integration to create a rich, seamless, and data-driven user experience.

Recommended Plant to Test: Try searching for "Strawberry" or "Garden strawberry" (Fragaria × ananassa) to see the full functionality of the Digital Herbarium in action!

APIs & Data Sources

  • Trefle.io REST API - https://trefle.io | GitHub
    The comprehensive botanical database providing scientific and common plant names, family classifications, and taxonomic information for over 400,000 plant species worldwide.
    Enhancement: Since Trefle.io primarily uses scientific names for accurate searches, I created a local CSV file (commonplants.csv) containing 50 commonly searched plants with their scientific name mappings. This allows users to search using familiar common names like "Snake Plant" or "Peace Lily," which are then automatically translated to their scientific names (e.g., "Dracaena trifasciata") before querying the API. When a match is found, a "Did you mean" suggestion appears at the top of search results, improving the user experience for non-experts while maintaining search accuracy.
  • Pixabay API - https://pixabay.com/api/docs/
    Used as a fallback image source when Trefle.io does not provide a plant image. Pixabay provides royalty-free images under the Pixabay License.
    Note: To properly credit the image source, I added a "Fetched by Pixabay" label that appears in the bottom-left corner of any image sourced from Pixabay, making attribution clear and visible to users.
